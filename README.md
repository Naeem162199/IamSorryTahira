# For Tahira — Interactive Apology Site

Static GitHub Pages site. No build process required.

## Images
Replace these five files in `assets/images/` with your own JPG/PNG images using the same filenames:
- `hero.jpg` — main photo together
- `story-1.jpg` — memory
- `story-2.jpg` — memory
- `her.jpg` — Tahira
- `me.jpg` — you

The current `.svg` files are only temporary visual placeholders. After adding your JPG/PNG files, change the five image paths in `index.html` from `.svg` to your new extension.

## GitHub Pages
Upload the contents to a repository, then use Settings → Pages → Deploy from branch → `main` → `/ (root)`.
