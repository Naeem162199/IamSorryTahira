# IamSorryTahira

## Important
This version is intentionally a **single-file GitHub Pages site**. CSS and JavaScript are inside `index.html`, so it will still render even if you only upload `index.html`.

Images are optional. Replace these paths later with your real images:
- `assets/images/hero.jpg`
- `assets/images/story-1.jpg`
- `assets/images/story-2.jpg`
- `assets/images/her.jpg`
- `assets/images/me.jpg`

The site displays a soft placeholder automatically when an image is missing.

## GitHub Pages
Upload the contents of this folder to the root of the `IamSorryTahira` repository, then make sure Pages is deploying the `main` branch from `/root`.
